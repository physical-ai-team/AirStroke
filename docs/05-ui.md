# 5. UI 요구사항

프론트엔드는 **바닐라 JS, 빌드 도구 없음**입니다. 외부 라이브러리가 필요하면 `web/<영역>/vendor/`에 파일로 넣습니다(CDN 금지 — 시연 중 네트워크 문제 방지). gateway와 주고받는 메시지 형식은 [03-protocol.md](03-protocol.md)에 있습니다.

## PC 그림판 — `web/canvas/` (조아람)

### 화면 구성
- **캔버스 2겹**
  - 아래층: 그림 누적. 지우개와 PNG 저장은 이 층만 대상으로 합니다.
  - 위층: 손 뼈대, 커서, 제스처 라벨. 매 프레임 지우고 다시 그립니다.
- 세션을 만들면 QR 코드를 표시하고, 폰이 연결되면 QR을 숨깁니다(`status.mobile_connected`).

### 기본 시각 요소 = 손 뼈대 오버레이
시청자는 발표자의 손을 볼 수 없으므로 **뼈대 오버레이가 손동작을 보여주는 주 수단**입니다.
- 21점과 연결선을 그립니다. 좌표에는 gesture와 같은 변환(반전 + 프레임 비율을 반영한 중앙 `ACTIVE_AREA` 매핑, `landmarks`의 `width`·`height` 사용)을 적용합니다 → [04-gestures.md](04-gestures.md) ⑤
- **제스처 라벨**: 손 옆(손목 또는 검지 끝 근처)에 현재 상태를 표시합니다. `commands.action` 기준입니다.

  | action | 라벨 |
  |---|---|
  | `draw` | ✏️ 그리기 |
  | `move` | ✌️ 이동 |
  | `erase` | ✋ 지우개 |
  | `idle` | ✊ 대기 (손이 없으면 숨김) |
- **상태별 표현**
  - `draw`: **검지 끝(8번)을 강조**합니다(크고 진한 점이나 펜 색 링).
  - `move`(펜 든 상태): **뼈대를 흐리게** 그립니다(투명도를 낮춤).
  - `erase`: 지우개 범위를 원으로 표시합니다.
  - `idle`: 기본 스타일로 그립니다.

### 그리기
- `action=draw`이고 `stroke_id`가 직전과 같으면 직전 커서에서 현재 커서까지 선을 긋습니다. `stroke_id`가 바뀌면 새 선을 시작합니다(이전 좌표 초기화).
- 선은 stroke 단위로 기록합니다(실행 취소에 필요).

### 폰 카메라 PiP 패널 (선택 기능)
- **기본값은 꺼짐**입니다.
- 켜기/끄기 버튼이 있어야 하고, 위치를 바꿀 수 있어야 합니다(네 모서리 중 선택 또는 드래그).
- 켜면 `{"type":"pip","enabled":true}`, 끄면 `false`를 보냅니다. **꺼져 있는 동안 gateway는 영상을 PC로 보내지 않습니다.**
- 셀카(`mirror=true`) 영상은 좌우를 반전해서 보여줍니다(사용자가 보기에 자연스럽게).

### FPS·지연시간 표시
- **화면 공유 화질에서도 읽히도록 크게** 표시하고, 켜고 끌 수 있게 합니다.
- 표시 항목: 화면 갱신 FPS, 랜드마크 수신 FPS, 전체 지연(ms). 3단계부터는 구간별 지연도 펼쳐 볼 수 있게 합니다.
- 전체 지연 = PC 표시 시각(gateway 시계로 환산) − `trace.capture`

### 시연 모드 토글
커서, 손 뼈대, 제스처 라벨을 **굵고 크게** 그립니다.

### 5단계 기능
- 지우개 (`action=erase`, 손바닥)
- 색상 변경 (UI 팔레트)
- 실행 취소 (stroke 단위)
- PNG 저장 (아래층 캔버스만)

> 색상 변경과 실행 취소를 제스처로 할지, 버튼·키보드로 할지는 5단계 시작 때 정합니다.

### 단독 개발
`tools/mock_commands.py`, `tools/mock_landmarks.py --loop`를 실행하면 vision·gesture·폰 없이 개발할 수 있습니다(gateway의 PC WebSocket 필요).

## 폰 카메라 페이지 — `web/mobile/` (박민성)

- URL `?s={sid}`에서 세션을 읽어 `wss://…/ws/mobile/{sid}`로 연결합니다.
- `getUserMedia`를 쓰므로 HTTPS가 필수입니다. HTTPS가 아니면 안내 문구를 보여줍니다.
- **후면/전면 카메라 전환**. 전면 카메라일 때만 프레임 헤더에 `mirror=true`를 넣습니다.
- 해상도·fps·JPEG 품질은 `/api/config`에서 받습니다(기본 640x480, 15fps, 품질 70). 하드코딩하지 않습니다.
- JPEG 인코딩은 `canvas.toBlob(…, "image/jpeg", quality/100)`으로 하고, 바이너리 프레임 형식으로 보냅니다.
- **흐름 제어**: ack를 받지 않은 프레임이 `max_inflight_frames`(2)장이면 이번 프레임은 버립니다.
- ping을 받으면 즉시 pong으로 답합니다(시계 동기화).
- 연결 상태, 송신 fps, 버린 프레임 수를 화면에 표시합니다(디바이스·네트워크 테스트용).
- 권장: 시연 중 화면이 꺼지지 않도록 Screen Wake Lock API를 사용합니다(지원하는 브라우저에서만).
