# 9. 시연

## 시연 환경
- **장소**: 집. **방식**: Zoom 화면 공유로 **PC 브라우저 창만** 보여줍니다.
- **시청자는 발표자의 손을 볼 수 없습니다** → 손 뼈대 오버레이와 제스처 라벨이 손동작을 전달합니다. 폰 영상 PiP는 실제 손을 보여주고 싶을 때만 켭니다.
- **같은 노트북**(Ryzen 7 5700U, 16GB, 내장 그래픽)에서 Zoom, Docker(WSL2), 브라우저, CPU 추론이 함께 돌아갑니다.

## 화면 공유를 고려한 UI
| 요소 | 기본값 | 이유 |
|---|---|---|
| 손 뼈대 + 제스처 라벨 | 켜짐 | 손이 안 보이는 시청자에게 동작을 전달 |
| 시연 모드 (굵고 크게) | 시연 때 켬 | 화면 공유 압축 화질에서도 보이게 |
| FPS·지연시간 (크게) | 켜고 끌 수 있음 | 성능을 시연 중에 보여줄 수 있게 |
| 폰 영상 PiP | **꺼짐** | 켜면 PC로 영상이 전송되어 부하가 늘어남 |

자세한 내용은 [05-ui.md](05-ui.md)에 있습니다.

## 성능 조절 (`.env` → `docker compose up -d`)
Zoom을 켠 상태에서 버벅이면 위에서부터 차례로 낮춥니다.

| 설정 | 기본값 | 낮춘 값 예시 | 효과 |
|---|---|---|---|
| `CAMERA_FPS` | 15 | 10 | 전체 부하가 비례해서 줄어듦 |
| `CAMERA_WIDTH` / `CAMERA_HEIGHT` | 640 / 480 | 480 / 360 | 인코딩·전송·추론 부하 감소 |
| `JPEG_QUALITY` | 70 | 60 | 전송량 감소 |
| `NUM_HANDS` | 1 | 1 | 2로 올리면 추론 부하 증가 |
| PiP | 꺼짐 | 꺼짐 | 켜면 PC 전송·디코딩 추가 |

## 준비 체크리스트와 문제 해결
루트 [README.md](../README.md)의 **"시연 체크리스트"** 와 **"문제 해결"** 섹션을 따릅니다.
- 전원 연결, Windows 전원 모드 "최고 성능", WSL 메모리 상한(`.wslconfig`)
- 폰에서 인증서 경고 미리 수락
- Zoom은 브라우저 창만 공유, 시연 중 Zoom 웹캠 끄기
- 예비용 시연 녹화 영상 준비
- 와이파이 기기 간 통신 차단 시 폰 핫스팟, IP가 바뀌면 `gen_cert.py` 재실행, 방화벽 8443 허용

## 시연 진행 (초안)
1. 그림판 화면 공유 → QR 표시 → 폰으로 스캔해 연결 (시청자에게 페어링 과정을 보여줌)
2. 손을 올려 뼈대 오버레이 표시 → 주먹(✊ 대기) / 검지(✏️ 그리기) / 두 손가락(✌️ 이동) / 손바닥(✋ 지우개) 순서로 시연
3. 간단한 그림 그리기 → 색상 변경 → 실행 취소 → PNG 저장
4. FPS·지연시간 표시를 켜고 아키텍처 설명 (필요하면 PiP를 잠깐 켜서 실제 손 보여주기)
5. 라이브가 실패하면 예비 녹화 영상으로 전환
