# PRD — 폰 카메라 페이지 & 디바이스·네트워크 측정 (담당: 박민성)

- 범위 폴더: `web/mobile/` (이 문서 포함). 상위 문서: [01-overview](../../docs/01-overview.md), [03-protocol](../../docs/03-protocol.md), [05-ui](../../docs/05-ui.md), [06-roadmap](../../docs/06-roadmap.md)
- 상태 표기: ✅ 구현됨 · 🔶 일부 · ⬜ 미구현 · ❓ 팀장 확인 필요
- 작성: 2026-10-29 (초안 v0.1)

## 1. 목적
폰 카메라 영상을 **낮은 지연으로 안정적으로** gateway에 보내고, 시연 환경(집 Wi-Fi, Zoom 동시 실행 노트북)에서 **fps·지연시간을 측정해 설정값(`.env`)을 정할 근거**를 만든다.

성공 기준
1. QR 스캔 후 **10초 안에** 프레임 송신이 시작된다(인증서 경고 수락 이후).
2. 시연 기본 설정(640x480, 15fps, 품질 70)에서 **송신 fps ≥ 14**, 폰에서 버린 프레임 **< 5%** (같은 Wi-Fi 기준). ❓
3. 10분 연속 시연에서 끊김·화면 꺼짐 없이 유지되고, 끊겨도 **5초 안에 자동 재연결**된다.
4. 전체 지연(촬영 → PC 표시)의 구간별 수치를 기기·네트워크별 표로 남긴다(7절).

## 2. 사용자와 상황
| 사용자 | 상황 | 필요한 것 |
|---|---|---|
| 발표자(시연자) | 폰을 거치대에 두고 손을 비춤, 폰 화면은 거의 안 봄 | 한 번 누르면 계속 송신, 화면 안 꺼짐, 끊기면 알아서 재연결 |
| 팀원(개발·통합) | 기기/네트워크를 바꿔 가며 시험 | 연결 상태·fps·버림·ack 왕복이 한눈에, 측정값 기록·내보내기 |
| 시청자 | 폰 화면을 보지 않음 | (간접) PC의 손 뼈대가 부드럽게 따라옴 |

## 3. 범위
- **포함**: 카메라 페이지 전체(연결·캡처·인코딩·송신·흐름 제어·시계 동기화 응답·상태 표시), 디바이스·네트워크 시험, 지연·fps 측정과 결과 정리
- **제외**: gateway 엔드포인트 구현(팀장), PC 쪽 지연 표시(조아람), vision/gesture 처리. WebRTC(D-001에서 제외)

## 5. 비기능 요구사항
- 바닐라 JS, 빌드 도구·CDN 없음(05-ui). 외부 라이브러리 필요 시 `web/mobile/vendor/`
- 설정값 하드코딩 금지 — 해상도·fps·품질·inflight는 `/api/config`. 페이지 내부 상수(재연결 백오프, 통계 창)는 `app.js` 상단에 모은다
- 대상 브라우저: Android Chrome(1순위), Samsung Internet, iOS Safari(팀원 기기 있으면) ❓
- 10분 연속 송신 시 메모리 증가 없음(통계 배열 길이 제한)

## 9. 열린 질문 (팀장 확인)
- **Q1 프레임 방향**: 폰을 세로로 들면 480x640(세로) 프레임이 간다. vision/gesture/그림판이 세로 프레임을 가정해도 되는가, 아니면 폰 페이지가 항상 가로(640x480)로 맞춰야 하는가? (`ACTIVE_AREA` 매핑과 캔버스 비율에 영향)
- **Q2 seq 규칙**: 현재 폰에서 버린 프레임에는 seq를 매기지 않는다(보낸 것만 연속 번호). 하류에서 seq 공백을 "버림"으로 집계한다면 이 규칙을 문서에 명시해야 한다.
- ~~Q3 ack 누락~~: **해결** — gateway 코드(`ws.py` `on_frame`) 확인 결과 publish 예외는 수신 루프 밖으로 나가 연결이 닫히고, 폰은 재연결하며 대기 목록을 비운다. 형식이 틀린 프레임만 ack 없이 남으므로 폰에 3초 타임아웃(M-25)을 안전장치로 두었다. (이전 메모: 문서상 형식이 틀린 프레임은 ack를 보내지 않는다. 폰은 올바른 형식만 보내므로 정상 경로에선 문제없다. 남은 질문: publish 중 Redis 오류가 나면 ack 없이 예외로 연결이 닫히는가, 아니면 소켓이 열린 채 ack만 안 오는가? 후자면 대기 2장이 막혀 송신이 멈춘다 → 폰 타임아웃(M-25) 필요.)
- ~~Q4 세션 거절~~: **해결** — close 4404/4409 (D-016). M-05 구현.
- ~~Q5 mock 서버~~: **불필요** — `tools/ws_client.py`가 생겼다.
- **Q6 포트 8443 충돌**: 리그 오브 레전드 클라이언트가 실행 중이면 로컬 8443을 사용한다(이 PC에서 확인). 시연 PC에서는 게임 클라이언트를 끄거나 `GATEWAY_PORT`를 바꿀 수 있어야 한다 → README 문제 해결에 추가 제안.
